별을 입는 아뜰리에 개인정보처리방침

시행일 2026년 9월 22일

아이가 그린 그림이 마법으로 옷이 되는 앱입니다. 아이가 쓰는 앱인 만큼, 무엇을 받아 어디에 쓰고 언제 지우는지 짧고 분명하게 적었습니다.

한눈에 보기

  • 계정도 로그인도 없습니다. 이름·나이·연락처·위치를 묻지 않습니다.
  • 아이가 그린 그림만 옷 마법 서버로 보냅니다. 옷 그림을 만들기 위해서입니다.
  • 광고가 없고, 추적하지 않으며, 어떤 정보도 팔지 않습니다.
  • 보낸 그림과 만들어진 옷 그림은 90일 뒤 자동으로 지워집니다.

1. 서버로 보내는 것

옷 마법을 걸 때만 아래를 우리 서버로 보냅니다. 평소에 앱을 쓰는 동안에는 아무것도 보내지 않습니다.

무엇을왜얼마나 둡니까
아이가 그린 도안 그림옷 그림을 만들기 위해90일 뒤 자동 삭제
의뢰 번호와 주민 번호어떤 이야기의 어떤 옷인지 구분하려고90일 뒤 자동 삭제
만들어진 옷 그림결과를 돌려주고, 잘못 나왔을 때 확인하려고90일 뒤 자동 삭제
만든 횟수·걸린 시간·드는 값서버를 운영하고 비용을 확인하려고계속 보관 (그림이나 사람과 연결되지 않는 숫자 기록입니다)

이름, 생년월일, 성별, 연락처, 주소, 위치, 연락처 목록, 사진첩의 사진, 광고 식별자는 모으지 않습니다. 그림에는 누가 그렸는지가 함께 담기지 않습니다.

2. 기기 안에만 남는 것

그리던 그림, 만든 옷, 이야기 진행 상황, 만들어 둔 색은 기기 안에만 저장됩니다. 앱을 지우면 함께 사라지며, 우리는 이것을 가져가지 않습니다.

3. 맡기는 곳

옷 그림을 만들려면 그림을 다음 회사의 서비스로 보내야 합니다.

  • Google Cloud — 서버 운영과 보관. 대한민국(서울) 지역에 둡니다.
  • Google Gemini API — 옷 그림 생성
  • OpenAI — 감사 편지 사진 생성

보내는 것은 그림과 짧은 영어 설명뿐이고, 누가 보냈는지는 보내지 않습니다. 두 회사는 유료 API로 받은 내용을 자사 모델 학습에 쓰지 않는다고 밝히고 있으며, 우리는 유료 API로만 보냅니다.

4. 광고와 추적

앱에 광고가 없습니다. 광고 식별자(IDFA)를 읽지 않고, 다른 앱이나 웹사이트에서의 활동을 따라다니지 않으며, 광고 회사에 무엇도 넘기지 않습니다.

5. 아이와 보호자

전 연령이 쓰는 앱입니다. 아이에게 이름이나 나이를 묻지 않고, 아이를 알아볼 수 있는 정보를 모으지 않습니다.

보호자께서 보낸 그림을 지우기를 원하시면 아래 이메일로 알려 주세요. 앱을 지우면 기기 안의 기록은 바로 사라지고, 서버에 남은 그림은 90일 안에 지워지며, 요청하시면 그보다 먼저 지워 드립니다.

6. 앱이 묻는 권한

  • 사진 앱에 저장 — 만든 옷 그림을 사진으로 저장할 때만 묻습니다. 사진첩을 읽지는 않습니다.
  • 같은 와이파이 안의 기기 연결 — 개발·시험용 서버에 연결할 때만 쓰입니다. 보통은 쓰이지 않습니다.

7. 안전하게 지키기

보내고 받는 것은 모두 https로 암호화합니다. 서버의 그림은 접근 권한이 있는 사람만 볼 수 있고, 90일 규칙에 따라 자동으로 지워집니다.

8. 유튜브 채널 관리 도구

저희는 저희가 소유한 유튜브 채널 @atelierofstarlight에 홍보 영상과 채널 배너를 올리기 위해 YouTube API Services를 쓰는 내부 도구를 씁니다. 이 도구는 개발자 본인만 쓰며, 외부에 배포하거나 팔지 않습니다. 앱과는 별개이며, 앱 이용자와는 아무 상관이 없습니다.

  • 다루는 것 — 저희 채널에 영상·썸네일·배너를 올리고 제목 같은 정보를 고칩니다.
  • 다루지 않는 것 — 다른 이용자의 유튜브 데이터를 읽거나 저장하지 않습니다. 시청 기록, 구독 정보, 댓글, 통계를 가져오지 않습니다.
  • 저장하는 것 — 저희 계정의 인증 토큰 하나를 개발자 기기 안에만 둡니다. 서버로 보내지도, 누구와 나누지도 않습니다.
  • 지우는 법 — 이 토큰은 더 쓰지 않게 되면 기기에서 지웁니다. 저희가 채널에 접근하는 권한은 Google 보안 설정에서 언제든 취소할 수 있고, 취소하면 도구는 즉시 아무것도 할 수 없게 됩니다.

이 도구는 YouTube 서비스 약관과 Google 개인정보처리방침을 따릅니다.
