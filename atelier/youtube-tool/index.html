무엇을 하는 도구인가

  • 저희 채널 @atelierofstarlight 에 홍보 영상과 썸네일, 채널 배너를 올립니다.

  • 다른 이용자의 유튜브 데이터는 읽지도 저장하지도 않습니다. 시청 기록·구독 정보·댓글·통계를 가져오지 않습니다.

누가 쓰나

개발자 본인 한 명뿐입니다. 가입도 배포도 없고, 공개된 주소나 설치 파일이 없습니다. 저희 계정의 인증 토큰 하나를 개발자 기기 안에만 둡니다.

YouTube API Services

이 도구는 YouTube API Services 를 이용합니다. 이용함으로써 YouTube 서비스 약관에 동의하며, Google 개인정보처리방침이 함께 적용됩니다.

저희가 채널에 접근하는 권한은 Google 보안 설정에서 언제든 취소할 수 있습니다.
